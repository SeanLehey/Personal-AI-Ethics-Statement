# Personal-AI-Ethics-Statement

### Where I Don't Use AI Tools:
I'm an avid reader and writer, and former editor/proofreader/transcriptionist by trade, so I've always taken pride in my writing. I feel that LLMs can be useful for a lot of applications, like tutoring, quizzing, and ironing out ideas, but there are certain applications where I'm not quite comfortable using them. One of those is interpersonal communication.

I don't want to interact with a facsimile of someone's thoughts, and I'm sure many other people feel the same way. To pass off an LLM's writings as my own would be a disservice to myself and the person I'm communicating with. However, I won't put people down for using LLMs in ways they see fit. It's simply my personal preference. All of the text in my GitHub projects was thought of and typed by me - no exceptions.

### Where I Do Use AI Tools:
As we grow further and further from the original release of publicly available LLMs in late 2023, it's clear that some approaches to these tools lend themselves to positive outcomes, and others - not so much. Using LLMs to "vibe code" can be fun for a laugh, but I think as time goes on, people will realize that they still need to go through the effort of reinforcement learning in order to hone their skills.

With that being said, I use LLMs to help me learn how to code, primarily with GDScript. It's my goal to understand what the AI is teaching me, and I make it a point to avoid blindly copying and pasting LLM-generated code output into my projects. All of my code is thoroughly commented, and I try to explain each element of my project to the reader in order to hold myself accountable and avoid signing off on an AI's codebase as opposed to creating my own.
