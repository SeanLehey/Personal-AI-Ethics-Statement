# Personal AI Ethics Statement

### Where I Don't Use AI Tools:
I don't want to interact with a facsimile of someone's thoughts, and I'm sure many other people feel the same way. To pass off an LLM's writings as my own would be a disservice to myself and the person I'm communicating with. This is not to say that others aren't free to use LLMs as they see fit. As far as my personal preference goes, all of the text in my GitHub projects was thought of and typed by me.

### Where I Do Use AI Tools:
I use LLMs to help me learn how to code. It's my goal to understand what the LLM is teaching me, and I make it a point to avoid blindly copying and pasting LLM-generated code output into my projects. I thoroughly comment all of my code, and I try to explain each element of my project to the reader in enough detail to demonstrate that I'm actually the one creating the project. LLMs can be a great tutor, but the actual learning and doing part of programming is still my responsibility.

### Why This Matters:
Tools like LLMs represent a huge step forward in education, business, and other fields. But I'm personally concerned about people becoming overly reliant on LLMs, especially once it gets to the point of supplanting one's own agency and ability to think critically. I think they make a great learning companion and multitool, but I'm hesitant to outsource all of my cognition to this technology. I think the best approach is to incorporate LLMs as an optional tool in our arsenal while staying informed about their strengths, limitations, and dangers as the technology evolves over time.
